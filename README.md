CodeAlpha Unemployment Analysis

Project Overview

This project analyzes unemployment trends in India using Python and data visualization.

Objectives

- Analyze unemployment trends over time.
- Compare unemployment rates across regions.
- Compare rural and urban unemployment.
- Examine unemployment before and during COVID-19.

Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

Data Cleaning

Missing values were removed, column names were cleaned, and date values were converted into datetime format.

Visualizations

- Unemployment trends over time
- Top 10 regions by average unemployment rate
- Rural versus urban unemployment
- Highest unemployment observations
- Before versus during COVID-19 comparison

Conclusion

This project uses Python-based data analysis and visualization to explore unemployment patterns across India.
